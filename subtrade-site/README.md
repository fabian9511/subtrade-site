# SubTrade Site

Next.js 14 marketing site for SubTrade Software Ltd., Calgary, Alberta.
Deployed to Vercel automatically on every commit to `main`.

**The project brief lives one level up, in the repo root `README.md`.** Read it
before making changes — it covers the layout, how deployment works, how to
publish a blog post, and two standing rules about privacy and how changes get
delivered.

Quick start:

```bash
npm install
npm run dev
```

To publish a blog post, copy `content/posts/TEMPLATE.md`, rename it to the URL
you want, fill in the header, write the post, and upload it to
`content/posts/`. Nothing else needs editing.
